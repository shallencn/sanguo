# 三国沙盘

单机的三国沙盘战略网页游戏：大地图铺地扩张、主城建设、武将战法、自动回合战斗。纯前端，没有后端，不联网。

- **在线试玩**：https://shallencn.github.io/sanguo/
- **当前进度**：第一阶段（地图、占地、资源、主城建筑、时间倍速、存档）
- **项目说明**：[开工说明.md](开工说明.md)
- **规则与数值**：[docs/设计.md](docs/设计.md)
- **立绘**：[docs/立绘提示词.md](docs/立绘提示词.md)、[docs/给ChatGPT的立绘指令.md](docs/给ChatGPT的立绘指令.md)

## 发布

`main` 分支一有更新（包括在网页上传立绘），GitHub 会自动测试、打包并发布到上面的网址，大约 1～2 分钟。

## 在自己电脑上运行（可选）

需要先安装 [Node.js](https://nodejs.org/)（22 或更新的版本）。

```bash
npm install
```

```bash
npm run dev
```

然后用浏览器打开命令行里显示的网址（一般是 http://localhost:5173/ ）。

其他命令：

| 命令 | 作用 |
|---|---|
| `npm test` | 运行自动化测试 |
| `npm run build` | 打包成可发布的网页（输出到 `dist/`） |
| `npx vite-node tools/dump-map.ts 123` | 把种子为 123 的地图打印成字符画（调地图生成时用） |

## 文件夹

| 位置 | 内容 |
|---|---|
| `src/data/` | 数据表：资源、土地等级、建筑、州与城池、势力、全局数值。想调数值、加内容改这里 |
| `src/core/` | 纯规则逻辑（不含界面）：地图生成、资源、建筑、领地、时间推进、存档 |
| `src/ui/` | 界面：地图画布、各个面板、弹窗 |
| `tests/` | 自动化测试 |
| `tools/` | 开发用小工具 |
| `docs/` | 设计文档、立绘提示词 |
| `public/portraits/` | 武将立绘 |
