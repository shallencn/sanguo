# 立绘提示词

40 个武将各一段，可以直接整段复制到绘图工具里。所有武将用同一套风格，只有最后“人物：”那一句不同。

## 出图与上传要求

- 竖图，比例 3:4，建议 768×1024（等比例更大也可以）。
- 文件格式 `.png`、`.jpg`、`.webp` 都可以。
- 文件名必须是下表里的拼音，全部小写，例如关羽是 `guanyu.png`。
- 上传到仓库的 `public/portraits/` 文件夹（`main` 分支）。上传后等 1～2 分钟自动发布，刷新游戏网页即可。
- 立绘从第二阶段（武将出现）开始在游戏里显示，届时发布流程会自动把图片压缩成合适的大小。在那之前上传的图先存在仓库里。
- 没有上传的武将，游戏里自动显示占位卡牌，不影响游玩。
- 画面里不要有文字、印章、水印、边框；脸部尽量落在画面上半部分的中间，战报头像会自动从这里裁出方形。
