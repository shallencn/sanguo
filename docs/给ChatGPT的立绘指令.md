# 给 ChatGPT 的立绘指令

用法：在 ChatGPT 里连接好 GitHub 仓库 `shallencn/sanguo` 之后，把下面方框里的整段文字复制给它。
最后一行"本次任务"按需要改，比如"魏国的 12 个""只做关羽和张飞""把赵云重画一张"。

```
你已经连接了我的 GitHub 仓库 shallencn/sanguo。这是一个三国题材的网页游戏，请你帮我生成武将立绘，并把图片直接提交到仓库里。

【先读文档】
请先读仓库里的 docs/立绘提示词.md。里面有 40 个武将，每个武将有一个拼音文件名和一段完整的绘图提示词。

【出图要求】
1. 严格使用文档里的提示词原文出图，不要改风格，不要自己发挥构图。
2. 竖图，比例 3:4，尺寸 768×1024 或等比例更大。格式 PNG。
3. 半身像，取胸部以上，人物居中，脸部落在画面上半部分的中间。
4. 画面里不能出现任何文字、印章、水印、签名、边框。
5. 40 张图要像同一位画师画的：同样的写实厚涂风格、同样的深色背景和光线。
6. 人物形象要原创，不要模仿任何现有游戏、影视剧、漫画里的造型。

【保存位置和文件名】
1. 每张图保存到仓库的 public/portraits/ 文件夹。
2. 文件名用文档"文件名对照表"里的拼音，加上扩展名，例如关羽是 public/portraits/guanyu.png。
3. 文件名全部小写，不要有空格、中文或其他字符。一个武将只保留一张图。

【提交规则】
1. 直接提交到 main 分支。
2. 提交说明写成"添加立绘：关羽"或"添加立绘：魏国 12 人"这种格式。
3. 只允许新增或替换 public/portraits/ 里的图片文件。不要修改、移动、删除仓库里的其他任何文件。
4. 开始之前先看一下 public/portraits/ 里已经有哪些图片。已经有图的武将跳过，除非我明确说要重画。
5. 每做完一批，用一张表告诉我：这次完成了哪些武将（文件名）、还剩哪些没做。

【做不到的时候】
如果你没有办法直接往仓库里提交图片文件，请不要假装已经提交，直接告诉我。然后把图片按上面的文件名给我下载，我自己上传到 GitHub。

本次任务：先做魏国的 12 个武将。
```

## 说明

- 图片提交到 `main` 分支后，GitHub 会自动重新发布游戏，大约 1～2 分钟，不需要再做任何操作。
- 如果 ChatGPT 说它不能直接提交图片（它的 GitHub 连接有可能只能读、不能写），就让它把图给你下载，
  然后在 GitHub 网页上手动上传：进入仓库的 `public/portraits/` 文件夹 → 右上角 **Add file** → **Upload files** →
  把图片拖进去 → 点绿色的 **Commit changes**。
- 对某张图不满意：让它重画同一个武将，用同样的文件名覆盖即可。
